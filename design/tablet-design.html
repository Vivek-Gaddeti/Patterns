Two Pointers

Is there a pair in [1, 3, 4, 6, 8, 11] that adds up to 10? Sketch how the two pointers move, then check the card.

Draw with your stylus. A finger scrolls the page.

Use it when the array is sorted and you need a pair. Start at both ends; move the left pointer up if the sum is too small, the right one down if it is too big.

def pair_sum(a, target):
    i, j = 0, len(a) - 1
    while i < j:
        s = a[i] + a[j]
        if s == target: return [i, j]
        if s < target: i += 1
        else: j -= 1
    return []

Solve portrait, and Practice

  • Portrait: Problem, Code and Scratch become three tabs. No more scrolling between the statement and the editor.
  • Practice: problems fold under their pattern with a progress count. Rows are 56px tall and the whole row opens the problem.
  • The pattern name stays hidden until you choose to group by it, so "guess the pattern" practice still works. The default view can stay mixed.
  • Bottom bar: shows on touch screens only. Laptops keep the top navigation.
